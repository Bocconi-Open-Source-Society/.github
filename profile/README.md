Students building, learning, and sharing open source at Bocconi University.

Our mission is to achieve `n` PRs merged into open-source projects for the `n-th` semester since our inception.

# Projects & Contributions
Here we collect some cool projects we are trying to contribute to:

- [x] [Conda](https://github.com/conda/conda): a system-level, binary package and environment manager running on all major operating systems and platforms.
- [ ] [PyTorch Lightning](https://github.com/Lightning-AI/pytorch-lightning): Pretrain, finetune any AI model of any size on 1 or 10,000+ GPUs with zero code changes.
- [ ] [Genesis](https://github.com/Genesis-Embodied-AI/Genesis): a generative world for general-purpose robotics & embodied AI learning.
- [ ] [OpenBB](https://github.com/OpenBB-finance/OpenBB): financial data platform for analysts, quants and AI agents.
- [ ] [Mesa](https://github.com/mesa/mesa): open-source Python library for agent-based modeling, ideal for simulating complex systems and exploring emergent behaviors.
